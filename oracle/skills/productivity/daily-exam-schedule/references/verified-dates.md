## Source reliability ranking
1. Official exam board PDFs (AQA/OCR/Edexcel direct download)
2. School timetables (collate all boards, signed off by exams officers)
3. Aggregation sites with stated sources (Save My Exams, NUM8ERS, BBC Bitesize)
4. The Student Room exam chat threads (confirmed by student community)
5. Tutor/study sites (SimpleStudy, StudyGuru -- use with caution, known to have session errors)
