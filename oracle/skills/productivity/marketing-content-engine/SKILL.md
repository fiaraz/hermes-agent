## Content types

### Blog posts

Topics that work well:
- "How to prepare for A-level Chemistry Paper 2" (seasonal, pre-exam)
- "The transition from GCSE to A-level Science: what changes" (for prospective students)
- "5 common mistakes in mole calculations" (demonstrates expertise)
- "Why UK universities value strong A-level Chemistry" (for international parents)
- "What examiners look for in 6-mark questions" (leverage examiner experience)

Post format:
```
Title: [SEO-friendly, compelling]

**Target audience:** [Parents / Students / Both]

**Reading time:** X minutes

---

[Intro paragraph - hook, state the problem]

[Body - teach something valuable, demonstrate expertise]

[Conclusion - call to action, mention availability]
```

### Testimonial / Case study

Structure:
```
**Student:** [Name], [Subject], [Grade achieved]
**Background:** [Starting point, challenges]
**The approach:** [Teaching method, focus areas]
**The result:** [Outcome, grade, university destination if applicable]
**In their words:** [Quote if available]
```

For the world #1 result, use this carefully -- not boastfully:
```
"One of my students achieved the highest A-level Chemistry score in the world in 2024 -- a testament to what focused, structured teaching can achieve. But I'm equally proud of every student who moves from a U to a C, or from dreading science to genuinely enjoying it."
```

## Process

### Step 1: Clarify requirements

Ask the user for:
- Content type (blog / newsletter / social / testimonial / web copy)
- Purpose (what they want to achieve)
- Target audience (parents / students / schools)
- Key message or topic
- Any specific achievements or points to highlight
- Tone (professional / warm / authoritative / encouraging)
- Platform if social media (X / FB / LinkedIn)

### Step 2: Draft content

Write a first draft incorporating:
- The user's unique selling points (31 years, examiner, #1 world result, international support)
- Clear value for the reader
- Specific, actionable advice (not generic)

### Step 3: Humanize

Apply the humanizer technique:
- Remove AI writing patterns (em dashes, rule of three, "not only but also", participle phrases)
- Remove promotional language ("vibrant", "cutting-edge", "revolutionary")
- Remove filler and hedging
- Add natural voice and personality
- Vary sentence rhythm
- Be specific, not vague

Step 3 is critical. Raw AI-generated marketing copy is obvious and off-putting.

### Step 4: Present for review

Show the draft with a note about:
- Audience fit
- Call to action
- Any alternative versions (different lengths, different angles)

### Step 5: Deliver

Once approved:
- For blog posts: write to `~/tutoring-materials/content/blog/{topic-slug}.md`
- For social posts: offer to post directly via xurl skill (if X/Twitter)
- For newsletters: format for email delivery

## Pitfalls

- **Don't sound boastful** about achievements -- state facts confidently, let them speak
- **Don't use tutor cliches** ("unlock your potential", "passionate about teaching") -- be specific instead
- **Don't write generic advice** that any tutor could write -- use your 31 years of examiner insights as a differentiator
- **Don't hard-sell** -- provide value first, offer services second
- **Never fabricate student results** -- only reference real outcomes
- **For international student content** -- focus on academic transition, NOT language support (user does not speak Mandarin/Chinese)
- **Always apply the humanizer** -- marketing content that reads like AI will not convert
